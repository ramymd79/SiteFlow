# MVP Scope

## الهدف
إثبات أن الشركة ستستخدم المنتج فعليًا لإدارة دورة:
**الموقع → مراجعة → حسابات → إقفال أسبوع → مستخلص**

## P0 — يجب أن يعمل
### Organization & Access
- Company
- Projects
- Users
- Roles
- Project assignments
- Phone number ↔ user mapping

### WhatsApp Capture
- Text / Image / PDF / Voice
- حفظ Original Evidence
- AI transcription/extraction
- Draft creation

### Supervisor Review
- Inbox
- تصحيح المشروع/الوصف/المبلغ/الشخص أو المورد
- تحديد نوع الحركة
- Bulk submit
- Daily close summary

### Finance
- Finance Inbox
- رؤية الأصل + AI + تعديلات المشرف
- Approve / Reject / Return
- Cost category / Project / Vendor / Advance link

### Advances
- أكثر من عهدة مفتوحة لنفس الشخص
- Ledger تراكمي
- Disbursement history
- Expense allocation
- Under-review amounts
- Remaining balance
- Settlement

### BOQ Lite
- Items / Unit / Contract qty / Unit price / Contract value
- Approved variation
- Current progress
- Previous certified
- Current claim

### Weekly Close
- Missing docs
- Pending supervisor items
- Pending finance items
- Open advances
- Progress not reviewed
- Variations pending
- Readiness score

### IPC / مستخلص
- Previous / Current / Cumulative
- Retention / Deductions / Advance recovery / Variations / Net due
- PDF/Export

### Client Portal
- Project progress / Photos / Payments / Certified IPCs / Outstanding / Approved variations

### Audit
- Original value / New value / Who / When / Source / Action

## P1 — بعد أول Paid Pilots
- WhatsApp project groups.
- Site diary.
- Material delivery capture.
- Subcontractor portal.
- Better offline/PWA.
- Accounting integrations.

## P2 — لاحقًا
- Native apps.
- Inventory.
- Purchase workflow.
- Payroll.
- Full accounting.
