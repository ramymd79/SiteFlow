# SiteFlow — التشغيل المحلي

من مجلد `web`:

```
npm install
npm run dev
```

افتح http://localhost:3000

كلمة السر لكل الحسابات: `demo1234`

| الدور | البريد |
|---|---|
| مالك | owner@demo.siteflow |
| حسابات | finance@demo.siteflow |
| مشرف | supervisor@demo.siteflow |
| مهندس | engineer@demo.siteflow |

## منتج العهد

الشاشات: رئيسية، سجّل مصروف، مراجعة، عهد، نواقص، تصدير، تدقيق، مشاريع، إعدادات.

مزامنة اللابتوب والموبايل: من إعدادات المالك → «فعّل غرفة مزامنة» → انسخ الرقم على الجهاز التاني.

فحص السيناريوهات: شاشة «فحص» بعد الدخول كمالك أو حسابات.
