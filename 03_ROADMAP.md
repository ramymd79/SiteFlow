# Roadmap

## Phase 0 — Validation Before Build
- 12–15 مقابلة.
- 4 شركات توافق Pilot.
- 3 شركات تدفع.
- جمع نماذج حقيقية بعد إخفاء البيانات الحساسة: عهدة، تسوية، مصروفات، BOQ، مستخلص، Progress sheet.

## Phase 1 — Foundation
Auth, multi-tenant organization, projects, roles, users, project assignments, audit basics.

## Phase 2 — Field Capture
WhatsApp webhook, text/image/voice/PDF, evidence storage, AI extraction, draft state, Supervisor Inbox, Daily Review.

## Phase 3 — Finance Core
Finance Inbox, expenses, vendors, advances ledger, approval/rejection, settlement, ageing, missing evidence.

## Phase 4 — Contract & Progress
BOQ Lite, progress updates, weekly review, variations, evidence/photos linked to progress.

## Phase 5 — Weekly Close + IPC
Weekly Close dashboard, readiness rules, client IPC, retention/deductions, export/PDF.

## Phase 6 — Client Portal
Client access, progress, photos, payments, IPCs, variations, visibility settings.

## Phase 7 — Paid Pilot Hardening
Logs, permissions, reliability, error handling, backup plan, support tooling, onboarding scripts.

## Phase 8 — Expansion
Only after real usage: WhatsApp groups, subcontractor IPC, accounting integrations, PWA/offline, native apps if justified.
