# SiteFlow — Project Starter

## الفكرة في سطر واحد
منصة بسيطة للمقاولات والتشطيبات تربط الموقع بالحسابات والإدارة:
**WhatsApp Capture → Supervisor Review → Finance Review → Weekly Close → مستخلصات سريعة → Client Portal**

## فلسفة المنتج
- بساطة شبيهة بـ Muamer.
- WhatsApp هو واجهة الإدخال الأساسية للموقع.
- Web Dashboard للمشرف والمحاسب والإدارة.
- المستخلصات جزء أساسي من المنتج.
- لا نبني ERP ضخم في البداية.
- كل حركة تحفظ أصلها: صوتية/صورة/نص + تفسير AI + تعديلات المستخدم + اعتماد المحاسب.
- الـAI يقترح ويصنف، لكنه لا يعتمد حركة مالية نهائية وحده.

## المستخدمون الأساسيون
1. صاحب الشركة / الإدارة.
2. مدير المشروع / المشرف.
3. المحاسب / المدير المالي.
4. مهندس الموقع / المستخدم الميداني.
5. العميل.
6. مقاول الباطن — لاحقًا في واجهة محدودة.

## الـMVP
- شركات / مشاريع / مستخدمين / صلاحيات.
- WhatsApp Capture.
- Supervisor Inbox.
- Finance Inbox.
- عهد متعددة ومتراكمة.
- مصروفات + فواتير + صور + صوتيات.
- Daily Review.
- Weekly Close.
- BOQ Lite.
- تقدم تنفيذ.
- مستخلص عميل.
- مستخلص مقاول باطن — نسخة أولية.
- Variation Orders.
- Client Portal.
- Audit Trail.
- Excel Export.

## خارج الـMVP
- General Ledger كامل.
- Payroll.
- HR.
- CRM.
- مخازن متقدمة.
- مشتريات شاملة.
- Asset Management.
- Native iOS/Android App.

## قاعدة العمل
قبل تنفيذ أي Feature كبيرة:
1. اشرح الفرضية.
2. اربطها بمشكلة مستخدم.
3. حدد تأثيرها على الـMVP.
4. ناقش البدائل.
5. لا توسع المنتج تلقائيًا إلى ERP.
