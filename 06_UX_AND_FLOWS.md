# UX & Core Flows

## Design Goal
المنتج يجب أن يشعر بأنه بسيط مثل Muamer، حتى لو كانت العمليات في الخلفية أعمق.

## Flow 1 — Expense via WhatsApp
1. المستخدم يرسل صوتية/صورة/نص.
2. النظام يرد: تم الاستلام ✅
3. AI يحولها Draft.
4. Draft يظهر في Supervisor Inbox.
5. المشرف يصحح إن لزم.
6. المشرف Submit.
7. المحاسب يراجع ويعتمد.
8. المصروف يدخل في العهد/المشروع.

## Flow 2 — Daily Review
المشرف يرى: Ready / Needs attention / Missing project / Missing amount / Duplicate suspect / Missing evidence.
ثم bulk confirm أو edit أو ignore أو submit to finance.

## Flow 3 — Multiple Advances
يعرض النظام إجمالي المستلم، المصروف المعتمد، تحت المراجعة، والمتبقي، مع Drill-down لكل عهدة.

## Flow 4 — Weekly Close
يعرض pending captures, pending finance, missing docs, unreviewed progress, open advances, pending variations، ثم Readiness %.

## Flow 5 — IPC
Progress approved → cumulative work → subtract previous certified → add variations → retention/deductions → draft IPC → review → issue.

## Flow 6 — Client Portal
العميل يرى فقط ما تسمح به الشركة: progress, gallery, payments, IPCs, variations, outstanding.
